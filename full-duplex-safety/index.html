Audio samples

Warning. This page contains unedited model audio and transcripts describing harmful activity.

A fixed, prerecorded interruption prompt is played into the user audio channel while the model is generating its response. Fixed-delay releases it a set time after the request ends; refusal-triggered releases it the moment a refusal cue appears in the model’s text stream. The prompt is the same for every request and contains no harmful content.

Each case is one behavior at one seed, run twice: once with no interruption and once with the interruption. The request, the voice and the decoding seed are identical. Every clip is a single mono track, mixed as a listener in the room would have heard it; the waveform separates it by source, with the user channel drawn upward in blue (request shaded blue, interruption shaded orange) and the model’s voice downward in green. Click a waveform to seek. These models greet the caller before the request has finished, so the first short downward burst is small talk rather than an answer.

These are selected successes, chosen for clarity: in each, the un-interrupted run refuses and the interrupted run does not. They are not a random sample and they are not the success rate.
